## 더미 데이터

### 설정

- **업체**: 코스트코 건강보조식품을 온라인으로 판매하는 가상 쇼핑몰
- **채널**: 쿠팡 · 네이버스토어 · 자사몰
- **제품**: 코스트코 건강보조식품 20종 (세부 분류 12개)
- **기간**: 2026년 6~9월, 월별 파일 4개
- **한 행의 단위**: 1주 구간 × 채널 × 제품
  - 한 달을 5구간(1~7일, 8~14일, 15~21일, 22~28일, 29일~말일)으로 나눔
  - 5구간 × 3채널 × 20제품 = 월 300행
- **파일 형식**
  - UTF-8 BOM으로 저장해서 엑셀에서도 한글이 깨지지 않음
  - 제목 행은 1줄, 금액은 원 단위

## CSV 형식 (제안안)

PRD 6장 "CSV 형식"이 아직 비어 있어서, 이 데이터에서 쓴 열 구성을 제안안으로 올립니다. 팀에서 확정되면 데이터와 문서를 거기에 맞춰 고치겠습니다.

**필수 7개** (지표 계산에 꼭 필요): `date`, `product`, `channel`, `ad_spend`, `visits`, `purchases`, `revenue`

| 열 | 뜻 | 비고 |
|---|---|---|
| `date` | 구간 시작일 (YYYY-MM-DD) | **필수**. 앞 7글자로 월을 묶음 |
| `period_end` | 구간 종료일 | |
| `days` | 구간 일수 | 29일~말일 구간은 2~3일 |
| `channel` | 판매 채널 | **필수** |
| `category` | 세부 분류 (종합비타민, 오메가3 등) | |
| `product` | 제품명 | **필수** |
| `unit_price` | 우리 판매가 (원) | |
| `discount_rate` | 할인율 (0.05 = 5%) | |
| `competitor_min_price` | 같은 채널 내 경쟁 최저가 (원) | 9월 쿠팡 정답의 핵심 근거 |
| `impressions` | 광고 노출수 | |
| `clicks` | 광고 클릭수 | |
| `visits` | 방문수 (광고 + 자연 유입) | **필수** |
| `add_to_cart` | 장바구니 담기 수 | |
| `purchases` | 주문 건수 | **필수** |
| `units` | 판매 수량 | |
| `revenue` | 매출 (원, 반품 빼기 전) | **필수** |
| `ad_spend` | 광고비 (원) | **필수** |
| `refund` | 반품액 (원) | |
| `holidays` | 구간 내 공휴일 수 | 함정 변수 |
| `stockout_days` | 구간 내 품절 일수 | 함정 변수 |

## 지표 공식

정답표(`answer_key.json`)는 아래 공식으로 계산했습니다. 분모가 0이면 `null` 입니다. 4번 지표 계산과 같은 공식을 쓰면 숫자가 그대로 맞아야 합니다.

| 지표 | 공식 |
|---|---|
| CTR | clicks / impressions |
| 구매전환율 (CVR) | purchases / visits |
| 장바구니율 | add_to_cart / visits |
| 장바구니→구매율 | purchases / add_to_cart |
| ROAS | revenue / ad_spend |
| CPC | ad_spend / clicks |
| CPA | ad_spend / purchases |
| 객단가 (AOV) | revenue / purchases |
| 방문당 매출 | revenue / visits |
| 전월 대비 증감률 | (이번 달 − 전달) / 전달 × 100 |

## 정답 시나리오 (요약)

> 9월 초 쿠팡에 경쟁 셀러가 등장해 우리 인기 제품 8개를 9~13% 싸게 올렸다. 운영자는 가격을 맞추지 않고 쿠팡 광고비를 약 50% 늘렸다. 방문은 유지됐지만 쿠팡 구매전환율이 5.16% → 2.43%로 떨어져, 9월 매출이 31.5% 감소했다.

- 전체 하락액의 **92.7%가 쿠팡**, 그중 경쟁가가 붙은 8개 제품이 **76.4%**
- 추석·공휴일·품절·할인은 **원인이 아닌 함정 변수**로 넣어 둠
- 채점 기준과 모범 AI 답변: [part3_answer_scenario.md](part3_answer_scenario.md)

## 검증한 내용

- 4개 파일 모두 300행, 열 20개, 모든 행의 열 개수 일치
- 모든 행에서 `revenue = units × unit_price × (1 − discount_rate)`, `purchases ≤ add_to_cart`, `clicks ≤ visits` 성립
- 위 공식으로 만든 별도의 KPI 계산 코드(JavaScript)에 4개 파일을 합쳐 넣었을 때 `answer_key.json` 과 전부 일치함

## 팀 연동 시 주의

- **전월 비교를 하려면 파일 여러 개를 합쳐서 넣어야 합니다.** 9월 파일만 넣으면 비교할 달이 없습니다. 그래서 CSV 읽기 작업에서 여러 파일을 한 번에 받는 기능을 넣을 예정입니다.
- **9월 쿠팡에는 `purchases = 0` 인 행이 있습니다.** 판매 1순위 자리를 완전히 뺏긴 주를 표현한 것입니다. 0으로 나누는 지표(객단가·CPA)가 `null` 로 처리되는지 확인하는 테스트로도 씁니다.
- **제품명은 코스트코에서 판매되는 제품을 참고했습니다.** 가격·판매량·경쟁가는 모두 가상입니다.

## 데이터 다시 만들기

스크립트는 고정된 난수 시드를 씁니다. 그래서 다시 실행해도 지금과 똑같은 파일이 나오고, 설정값을 바꿨을 때만 결과가 달라집니다.

아래 명령을 저장소 최상위 폴더에서 실행하면 `data` 폴더의 CSV 4개를 새로 씁니다. 기존 파일은 덮어씁니다.

```powershell
python tools/generate_sales.py
```

설정을 바꿔 다시 만들었다면 `answer_key.json` 과 정답 시나리오의 숫자도 다시 계산해야 합니다.
