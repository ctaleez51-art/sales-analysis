# PRD - 매출분석 툴

> 초안입니다. 팀 회의에서 (  ) 부분을 채워 확정합니다.

## 1. 목적
매출 CSV를 올리면 핵심 지표를 자동 계산하고, AI가 쉬운 말로 분석해 주는 도구를 만듭니다.

## 2. 사용자
- (예: 소상공인, 쇼핑몰 운영자)

## 3. 핵심 기능
| 기능 | 설명 | 담당 |
|---|---|---|
| 로그인 | 회원가입, 로그인 | 2번 |
| 결제 | 토스페이먼츠로 유료 결제 | 2번 |
| CSV 입력 | CSV 업로드, 읽기, OpenAI 연결 | 3번 |
| 지표 계산 | 매출 지표를 정해진 식으로 계산 (입력단과 공유) | 4번 |
| 결과 분석 | 계산 결과를 OpenAI가 해석해 출력 | 4번 |
| 대시보드 | 지표와 분석을 한 화면에 표시 | 5번 |

## 4. 사용 흐름
로그인 → 결제 → CSV 업로드 → 지표 계산 → AI 분석 → 대시보드 확인
