## 흐름

1. **로그인** — 로그인하지 않으면 화면이 가려집니다(2번).
2. **[예시 데이터로 시작]** → 맨 위 **결론 영역** "9월 매출 31.5% 감소 · 손님은 그대로인데, 사지 않았다." → 분해 줄(매출 = 방문 × 구매 전환율 × 객단가)에서 구매 전환율 칸 "여기서 무너짐" → KPI
   - 9월 매출 **27,356,180원 (-31.45%)**, 광고비 +23.07%, ROAS 3.95배, 구매전환율 2.99%
   - "숫자는 AI가 아니라 4번 계산 코드가 냈고, 3번 정답표와 일치합니다."
3. **판매 채널별 ROAS · 쿠팡 경쟁가 진단**
   - 쿠팡 ROAS 2.97배 (-66%), 경쟁 최저가가 우리보다 낮은 제품 8개
4. **질문** [광고비는 늘었는데 왜 매출이 안 늘었어?] → **분석 계획 카드**
   - "AI를 부르기 전에 무엇을 계산하고 무엇을 보낼지 먼저 보여 주고, 사람이 승인합니다."
5. **[승인하고 분석]** → 로딩(경과 초 · [중단]) → **AI 답변** — ✅ 확인된 사실 · 🤔 원인 후보("확정 아님") · 🎯 우선 액션 상자 → **실행 기록** 펼치기
6. **잘못된 CSV 올리기** — [CSV 올리기]로 `part5/test-csv/` 파일을 고릅니다.

| 파일 | 화면 안내 |
|---|---|
| `bad_format.csv` | 계산하지 않고 "4행 date: 날짜 형식(YYYY-MM-DD)이 아닙니다", "6행 ad_spend: 0 이상의 숫자가 아닙니다" |
| `sales_only_2026_08.csv` + `sales_only_2026_09.csv` (둘 함께) | 판매 지표만 있어도 분석 — 매출 · 객단가는 계산, 광고비 · ROAS · 전환율 · CPA 는 **"계산 불가 + 근거"**, 결론 "방문 · 구매 전환율을 알 수 없어 원인은 나눠 볼 수 없다." |
| `no_visits_column.csv` | 구매전환율만 계산 불가(근거: 방문 열 없음), 나머지 계산 |

- 필수 열은 **날짜 · 상품 · 채널(date · product · channel)** 3개입니다(10/1). 없는 지표는 0 이 아니라 "계산 불가"로 보여 주고 AI 에도 그렇게 넘깁니다.
- 멘트: "잘못된 값은 계산하지 않고 이유를 알려 주고, 빠진 지표는 0으로 채우지 않습니다. 틀린 숫자를 보여 주는 것보다 '모른다'고 하는 게 낫기 때문입니다."
- 쿠팡 판매자센터 **주문내역 원본** CSV 를 그대로 읽는 기능은 PR #11(병합 대기) — 병합된 뒤에만 시연하세요.
- 다시 [예시 데이터로 시작]을 누르면 원래 화면으로 돌아옵니다.

## 실제 AI로 할 때 주의

- **9/30 16:58 실제 AI 동작 확인** — 질문 "매출이 왜 떨어졌어?"로 200 · 약 12초, 답변 속 숫자가 계산 결과와 같음(`part5/REHEARSAL.md` 9/30 절). 시연 질문도 이것을 추천합니다.
- 승인은 **한 번만** 누릅니다. 응답까지 10~20초 걸리고, 10초가 넘으면 "평소보다 오래 걸립니다" 안내가 나옵니다(60초에 자동 중단).
- **하루 한도:** 무료 회원은 AI 분석 하루 5회, **실패해도 1회 줄어듭니다**(4번 서버가 OpenAI 호출 전에 한도를 뺌). 리허설로 발표 계정의 한도를 다 쓰지 않게 주의합니다.
  - 여유가 필요하면 ① 시연용 계정을 하나 더 만들거나 ② 계정 상자의 [프로 결제]로 **토스 테스트 결제**(실제 청구 없음)를 해 프로(무제한)로 올립니다.
- **"AI 서버 설정 문제" 카드가 나오면** 서버 메시지 괄호 안의 이유를 봅니다. "no credits"면 서버의 OpenAI 키 크레딧이 없다는 뜻(4번 · 키 교체 필요)이니 **다시 시도는 누르지 않습니다**(한도만 줄어듦).
- 대비책: AI가 실패해도 KPI · 차트 · 경쟁가 진단은 계산 코드 결과라 그대로 설명할 수 있습니다. "숫자는 코드가, 해석은 AI가" — AI가 없어도 숫자는 남습니다.

## 문제가 생기면

| 증상 | 해결 |
|---|---|
| 배포 주소가 안 열림 · 404 | 인터넷 확인 후 새로고침. 계속 안 되면 위 "로컬 (예비)" 로 |
| "사이트에 연결할 수 없음"(로컬) | 서버 창이 켜져 있는지 확인 후 새로고침(F5) |
| `Address already in use` | 8790을 쓰는 다른 서버를 끄거나 다른 포트로 실행 |
| 로그인이 안 됨 | 인터넷 연결, 주소가 `file://`이 아닌지 확인 |
| 로그인 화면이 안 나옴 | main 이 아닌 다른 브랜치를 로컬로 연 것 — 팀 저장소 main 에서 열기 |
| 서버 창이 멈춤(요청 기록이 안 올라옴) | Windows 검은 창을 클릭하면 선택 모드로 멈춤 — 창을 누르지 말고, 멈췄으면 `Esc` |
| 고쳤는데 옛 화면 | 브라우저 캐시 — 강력 새로고침(Ctrl+Shift+R) |
