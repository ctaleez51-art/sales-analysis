## 2. 지원 / 미지원 분석

### 지원
| 분석 | 설명 |
|---|---|
| 월별 지표 | 매출, 광고비, 방문, 구매 등 합계와 CTR, CVR, ROAS, CPA, 객단가 등 비율 (계산식은 PRD §6) |
| 전월 대비 증감률 | 매출, 광고비, 방문, 구매, ROAS, CVR, CPA, 객단가 |
| 판매 채널별 지표 | 채널마다 월별 지표 |
| 쿠팡 경쟁가 진단 | 이번 달 쿠팡에서 경쟁 최저가가 우리 판매가보다 낮은 제품 목록 |
| AI 해석 | 위 계산 결과를 받아 확인된 사실, 원인 후보, 다음 행동, 분석 한계로 나눠 설명 |

### 미지원
| 분석 | 이유 |
|---|---|
| 상품별 지표 | 계산 코드가 상품별로 묶어 계산하지 않음 |
| 주별, 일별 추이 | 월 단위로만 묶음 |
| 바로 전 달이 없는 비교 (예: 6월과 9월만) | 전월 대비를 계산하지 않음 |
| 순매출 (매출 − 반품) | 매출은 반품 전 금액으로만 계산 |
| 쿠팡 외 채널의 경쟁가 진단 | 진단 기준이 쿠팡으로 정해져 있음 |
| 두 데이터셋 결합, DB 직접 연결, 분석 코드 실행 | 만들지 않음 |
| AI가 새로 계산한 숫자 | AI는 계산된 결과만 해석함 |

## 3. 전처리 규칙
출처: 5번 `part5/csv.js` (대시보드에서 CSV를 올릴 때)

| 규칙 | 걸리면 |
|---|---|
| 파일 확장자가 `.csv`가 아님 | "CSV 파일이 아닙니다" |
| 빈 파일, 제목 행만 있음 | "빈 파일입니다", "데이터가 없습니다" |
| 필수 열 14개 중 빠진 열이 있음 | 빠진 열 이름을 보여 줌 |
| 칸 수가 제목 행과 다름 | 파일명, 행 번호를 보여 줌 |
| `date`가 YYYY-MM-DD 형식이 아님 | 파일명, 행 번호, 값을 보여 줌 |
| 숫자 열 11개(`unit_price`, `competitor_min_price`, `impressions`, `clicks`, `visits`, `add_to_cart`, `purchases`, `units`, `revenue`, `ad_spend`, `refund`)가 0 이상의 숫자가 아님 (빈칸 포함) | 파일명, 행 번호, 열 이름, 값을 보여 줌 |

- 오류가 하나라도 있으면 그 파일은 계산하지 않습니다. 오류는 최대 5개까지 보여 줍니다.
- 파일 맨 앞의 BOM은 지웁니다. 따옴표 안의 쉼표와 줄바꿈은 값으로 읽습니다.
- 여러 파일은 행을 합쳐서 계산합니다. 파일마다 열 구성이 달라도 필수 열만 있으면 됩니다.
- **하지 않는 것:** 결측치 채우기, 중복 행 지우기, 날짜 형식 자동 변환. 원본을 고치지 않고 오류로 알려 줍니다.

## 4. 데이터 흐름도

```
[사용자] CSV 올리기 (또는 예시 데이터)
   ▼
[5번 csv.js] 검사 ── 오류 ──▶ 오류 안내 (계산 안 함)
   ▼
[4번 result-engine.js] buildResult(rows) ── 지표 계산 (AI 안 씀)
   ▼
[5번 대시보드] KPI 6칸 · 월별 매출 · 구매 퍼널 · 채널별 ROAS · 쿠팡 경쟁가 진단
   ▼
[사용자] 질문 → 분석 계획 확인 → [승인]  (취소하면 AI를 부르지 않음)
   ▼
[4번 AI 서버 analyze-shop] 로그인 확인 → 하루 한도 차감 → OpenAI에 계산 결과 + 질문 전달
   ▼
[5번 답변 카드] 분석 글 표시 · 실행 기록 표
```

- AI에 보내는 것은 계산 결과(약 8KB)와 질문뿐입니다. 원본 CSV는 보내지 않습니다.
