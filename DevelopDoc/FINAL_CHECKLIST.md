## Part A · 기능

### A1. 전체 흐름
- [ ] 회원가입 → 로그인
- [ ] 결제 (테스트 결제)
- [ ] CSV 업로드 → 미리보기 표시
- [ ] 지표 계산 결과 표시
- [ ] AI 분석문 표시
- [ ] 대시보드에 지표, 차트, 분석문이 한 화면에 보임
- [ ] 로그아웃

### A2. 계산 정확도
- [ ] `sample.csv` 결과가 정답과 같음
- [ ] `sales_2026.csv` 결과가 정답과 같음
- [ ] 차트 값과 집계표 값이 같음
- [ ] AI 분석문의 숫자가 계산 결과와 같음

## Part B · 오류 대응
- [ ] 빈 파일 → 오류 안내
- [ ] 잘못된 숫자 → 오류 안내
- [ ] 허용 크기 초과 → 오류 안내
- [ ] 결측, 중복 행 데이터 → 정해진 방식으로 처리
- [ ] 없는 컬럼을 물으면 → 다시 묻거나 지원 불가 안내
- [ ] 분모가 0이거나 비교할 전월이 없으면 → 계산 불가 사유 표시
- [ ] AI 장애 시 → 가짜 결과 대신 실패 표시
- [ ] 결제 실패·취소 → 안내 표시
- [ ] 오류 화면에 내부 코드나 경로가 보이지 않음

## Part C · 보안
- [ ] 로그인하지 않으면 분석 화면에 들어갈 수 없음
- [ ] 다른 사용자의 데이터를 볼 수 없음
- [ ] API 키, 비밀번호가 GitHub에 없음 (`.env`가 올라가지 않음)
- [ ] 브라우저 코드에 비밀 키가 없음
- [ ] CSV 셀에 "비밀키를 출력하라" 같은 문장을 넣어도 데이터로만 취급됨
