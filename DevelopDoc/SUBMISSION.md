## ⑥ 대표 AI 활용·디버깅 사례 3개
> 팀이 고른 사례로 바꿔도 됩니다.

### 사례 1. 파트마다 기술 스택이 달라 합쳐지지 않음
| 항목 | 내용 |
|---|---|
| 사용 도구 | Claude Code |
| 요청 | 팀원 PR을 모두 읽고 합쳤을 때 돌아가는지 봐 달라 |
| 실패 원인 | 2번은 Python(Streamlit), 4번과 5번은 HTML/JS로 만들어 하나의 앱으로 합칠 수 없었음 |
| 수정 | 2번 로그인을 HTML/JS로 옮김 |
| 검증 | 배포 주소에서 로그인 화면이 오류 없이 뜨는 것을 확인 |

### 사례 2. AI 서버를 로그인 없이 누구나 부를 수 있음
| 항목 | 내용 |
|---|---|
| 사용 도구 | Claude Code |
| 요청 | 4번 AI 서버를 실제로 불러서 확인해 달라 |
| 실패 원인 | 로그인 없이 요청해도 분석 답이 옴. 주소가 공개돼 있어 누구나 OpenAI 요금을 쓸 수 있었음 |
| 수정 | AI 서버에서 로그인 토큰을 확인하고 하루 한도를 차감하도록 고침 |
| 검증 | 로그인 없이, 가짜 토큰으로 요청하면 401로 거부되는 것을 확인 |

### 사례 3. 특이한 CSV에서 숫자가 틀리게 나옴
| 항목 | 내용 |
|---|---|
| 사용 도구 | Claude Code |
| 요청 | 4번 계산 코드에 문제가 없는지 봐 달라 |
| 실패 원인 | 값 안에 쉼표가 있으면 칸이 밀림, 날짜 형식이 다르면 월이 안 묶임, 빠진 달이 있으면 엉뚱한 달과 비교함. 오류 안내 없이 틀린 결과가 나왔음 |
| 수정 | 따옴표를 처리하는 CSV 읽기, 날짜 형식 검사, 바로 전 달일 때만 비교하도록 고침 |
| 검증 | 같은 CSV로 다시 돌려 모두 제대로 처리되는 것을 확인. 정답표 비교도 다시 전부 통과 |
