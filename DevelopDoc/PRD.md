## 1. 목적
매출 CSV를 올리면 핵심 지표를 자동 계산하고, AI가 쉬운 말로 분석해 주는 도구를 만듭니다.

과제 원칙:
- 숫자는 반드시 코드가 계산합니다. AI가 숫자를 지어내면 안 됩니다.
- AI는 계산된 결과를 해석하는 데만 씁니다.
- AI 설명에 나오는 숫자는 계산 결과만 인용합니다.

## 2. 사용자
- 쇼핑몰 운영자

## 3. 목표 단계
과제는 Step 1~5로 나뉘며, 팀이 목표 단계를 정합니다.

| Step | 목표 | 통과 기준 |
|---|---|---|
| 1 | CSV와 질문으로 첫 분석 | 집계표·차트가 미리 구한 정답과 일치 |
| 2 | 저장·전처리·재현성 | 같은 데이터·설정으로 다시 실행하면 같은 수치 |
| 3 | 계획·도구 실행·검증 흐름 | 승인 후에만 실행, 실행 기록이 정답과 일치 |
| 4 | 대시보드·공유·분석 품질 | 필터·내보내기 수치 일치, 권한 경계 동작 |
| 5 | 확장·운영 준비 | 회귀 테스트 통과, 확장 기능 보안 검증 |

| 기능 | 설명 | 담당 |

## 8. 검증 데이터와 정답 (과제 제공)

**sample.csv (4행)**
```
month,region,sales
2026-01,서울,100
2026-01,부산,200
2026-02,서울,150
2026-02,부산,50
```
정답: 총 500, 서울 250, 부산 250, 1월 300, 2월 200, 전월 대비 약 -33.33%

**sales_2026.csv (36행, 12개월 × 3지역)**
정답:
- 총 매출 80,910 / 총 주문 733
- 서울 42,040 (52.0%) 1위
- 최고 월 12월 7,860 / 최저 월 3월 5,950
- 상반기 → 하반기 +9.4%
- 이탈 지역: 부산, 상반기 12,950 → 하반기 9,030 (-30.3%)
- 급성장 지역: 대구, 1월 870 → 12월 1,970 (약 2.3배), 연간 16,890

오류 샘플: 결측, 잘못된 숫자, 중복 행 (파일은 3번이 준비)

## 9. 오류 처리 (과제 Step 1 통과 테스트)
- 빈 파일, 잘못된 숫자, 허용 크기 초과 → 오류로 안내
- 없는 컬럼을 물으면 → 다시 묻거나 지원 불가로 안내
- 차트 값과 집계표 값이 같아야 함
- AI 장애 시 → 가짜 결과 대신 실패 표시

## 10. 보안
- API 키, 비밀번호는 코드에 넣지 않고 `.env`에 둡니다. `.env`는 GitHub에 올리지 않습니다.
- 중요한 키는 Claude에게도 직접 보여 주지 않습니다.
- 권한 검사는 화면에서 숨기는 것만으로 하지 않고 서버나 DB에서 합니다.
