## 1. 목적
매출 CSV를 올리면 핵심 지표를 자동 계산하고, AI가 쉬운 말로 분석해 주는 도구를 만듭니다.

## 2. 사용자
- 쇼핑몰 운영자

## 3. 핵심 기능
| 기능 | 설명 | 담당 |
|---|---|---|
| 문서·저장소 | PRD 등 문서 작성, 저장소 관리(merge 등) | 1번 이지연 |
| 로그인 | 로그인 화면, DB 만들기 | 2번 허규현 |
| 결제 | 토스페이먼츠로 결제창 붙이기 | 2번 허규현 |
| CSV 입력 | 더미 데이터 만들기, 정답 시나리오 만들기 | 3번 김보겸 |
| 지표 계산 | 지표 계산식을 코드에 고정, 입력단과 공유 | 4번 김성순 |
| 결과 분석 | 결과분석 출력, OpenAI API 연결 | 4번 김성순 |
| 대시보드 | 사용자 친화적인 화면, 전체 색·글꼴·버튼 모양·위치 결정 | 5번 이두규 |

## 4. 사용 흐름
로그인 → 결제 → CSV 업로드 → 지표 계산 → AI 분석 → 대시보드 확인
